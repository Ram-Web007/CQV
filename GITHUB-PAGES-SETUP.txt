CQV Technologies - GitHub Pages Setup

1. Extract this ZIP.
2. Upload ALL extracted files and folders to the root of your GitHub repository.
   index.html and .nojekyll must be in the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select your main branch and /(root), then Save.
6. Open the published website and submit the Contact form once.
7. Check info@cqvtechnologies.com and click the FormSubmit activation link.

After activation, Contact and Career form submissions are delivered to
info@cqvtechnologies.com. Career resume attachments can be up to 10 MB.

Page example: https://YOUR-USERNAME.github.io/YOUR-REPO/services.html
