CQV Technologies - Static HTML Export

Upload the contents of this folder to the document root of any static web host.
Open index.html directly, or upload the folder contents to any static web host. Portable relative links are used throughout.

Included:
- 12 published pages from the WordPress backup
- Divi styling, JavaScript, fonts, images, videos and other media
- Contact and career forms deliver leads to info@cqvtechnologies.com through FormSubmit

Static-site limitations:
- WordPress login, admin, database, search, feeds and PHP are not included.
- FormSubmit requires one-time activation from info@cqvtechnologies.com after the first test submission.
- Career resume attachments can be up to 10 MB.

All website pages use root-level HTML filenames (for example, services.html).
